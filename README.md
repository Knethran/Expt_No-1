AIM:
	To sketch the given drawing with dimensions using fusion 360 tool.
REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16GB of RAM (integrated graphics recommend 2 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload
PROCEDURE:
1. Open a new file and then select the sketch icon.
2. Select the plane of sketching.
3. Use Sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw to given sketch
<img width="331" height="532" alt="Screenshot 2026-10-05 105221" src="https://github.com/user-attachments/assets/3b52619b-817e-4ff0-9681-603d751cf23e" />

4. Use sketch modifying features (trim, mirror, move, etc.,) to edit the sketch
<img width="223" height="338" alt="Screenshot 2026-10-05 105834" src="https://github.com/user-attachments/assets/3290a109-21c2-42cf-b843-66f2e367f629" />

5. Use the Constraints feature and apply the Tangent tool to join the circles smoothly and create the required curves.
<img width="285" height="452" alt="Screenshot 2026-10-05 110525" src="https://github.com/user-attachments/assets/a4e1141d-759c-4879-bc49-9fce8cb036e3" />

6. Draw a vertical construction line through the centre of the sketch. 
7. Draw a horizontal construction line through the centre of the middle portion. 
8. Draw two concentric circles at the top with (diameters) Ø32 mm and Ø20 mm. 
9. Position the centre of the top circles 65 mm above the horizontal centre line. 
10. Draw the two outer side curves using R64 and make them symmetrical about the vertical centre line. 
11. Draw the middle outer circular portion with Ø66 mm and trim the unwanted portions. 
12. Draw the central four-lobed opening using R6 arcs and the Ø40 mm dimension. 
13. Draw the left and right circular end portions using R20 and R7 as shown. 
14. Draw the inner circles of the left and right portions with R10. 
15. Position the left and right end centres 47 mm from the vertical centre line on both sides. 
16. Draw the lower central circular portion with Ø20 mm and its inner hole with Ø10 mm. 
17. Create the connecting curves using R10 and R20. 
18. Apply the vertical dimensions 26 mm and 24 mm to position the side and bottom features correctly. 
19. Use Trim to remove the unwanted portions and form the final profile. 
20. Apply Tangent, Coincident, Symmetry, Horizontal/Vertical constraints wherever required. 
21. Check all the given dimensions and ensure that the complete profile matches the reference drawing. 
22. Finish the sketch after completing all the required dimensions and constraints. 
23. The finished sketch should look like this. 
24. Line – Used to draw the straight edges of the diagram.
    Circle – Used to create the circular holes/features in the diagram.
